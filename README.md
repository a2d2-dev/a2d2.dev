# a2d2.dev

Source for the static landing page of **A²D² — Agentic Agile Driven Development**, served at <https://a2d2.dev>.

- Plain HTML/CSS, no build step: `index.html`, `favicon.svg`, `og.png`.
- Deployed on Vercel (project `a2d2-dev`); every push to `main` deploys to production.
- Organization: <https://github.com/a2d2-dev> · X: [@neolf](https://x.com/neolf)

Preview locally: open `index.html` in a browser, or run `python3 -m http.server`.
