01 / methodology

Agile rhythm, driven by agents.

The methodology is larger than any single tool — it spans workflow skills and multi-model orchestration too. Three ideas sit at its core.

CHAIR

A strong model decides

A high-quality model chairs architecture and decisions — the CEO role that owns a piece of work.

ORCHESTRATE

Many models execute

A multi-model orchestration carries execution, with engineer and reviewer Agents routed to their own models.

CONTINUITY

Sessions stay tied together

The sessions belonging to one piece of work keep a relationship a person can read, review, and commit — across every handoff.

The main stage road

Each stage maps to an Agent. Default assignment in dsh-plugin:

grillCEO
to-specCEO
to-ticketsCEO
implementEngineer
code-reviewReviewer

Stage assignments and each Agent’s ordered provider/model candidates are live settings — change them without restarting the host.

02 / implementation

dsh-plugin: A²D² on DeepSeek Harness

dsh-plugin, from the a2d2-dev organization, lands A²D² inside DeepSeek Harness (DSH) as one installable plugin. What it gives DSH today:

Task aggregation

A task groups the sessions of one piece of work and records the handoff edges between them, in project-local documents. Main sessions can open_subtask, dispatch_subagent, and complete_task.

Session handoff

/handoff moves work from a long, expensive session to a fresh one without losing the thread — the successor continues from bounded continuation content.

Floating indicator

An at-a-glance orb by the composer tracks context length and cost, and warns as a session approaches the smart zone.

A²D² control panel

A GitHub Project and Issue entry inside DSH, connecting original requirements, continuous processing, decomposition, acceptance progress and the current Session.

GitHub watch

github_watch lets a session wait on a pull request without polling — merges, closes, CI results and review decisions arrive as messages, even to an idle session.

Notifications

When a task issue’s main session stops to wait for LF, one A²D²-worded message reaches LF’s phone through an installed notifier provider.

03 / get started

Install the prerelease

Download a2d2-dsh-a2d2-0.0.22.tgz from GitHub Release v0.0.22 (a2d2-dev on GitHub), keep it compressed, and install its absolute path through the desktop plugin manager or the app-provided CLI.

  • Node.js 22 or newer is required.
  • Verified on the matching DSH 0.2.1-rc.2 development host, not every official desktop version.
  • Fully quit and reopen DSH after upgrading.
  • Licensed under Apache-2.0.
  • Source and releases: github.com/a2d2-dev.
# install the release tarball into DSH
dsh plugin --profile desktop add \
  /absolute/path/a2d2-dsh-a2d2-0.0.22.tgz

04 / naming

A2D2→a2d2

A²D² is the brand and display form; a2d2 is the technical identifier — package name, directories, and service names all use it, because ² cannot appear in an npm package name. The package is @a2d2/dsh-a2d2.
